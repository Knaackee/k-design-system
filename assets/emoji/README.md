# Emoji catalog

Graphics: Twemoji 17.0.1, Twitter and contributors, CC BY 4.0.
https://github.com/jdecked/twemoji/tree/v17.0.1

Names, categories and keywords: GitHub gemoji, MIT.
https://github.com/github/gemoji

Both platforms use the same bundled SVG data. No runtime network requests.
Consumers may supply their own catalog, labels and renderers.
