# Kleine Beispiele

Inline-Code wie `project.status` gehört zum Satz.

```typescript
type Project = {
  name: string;
  active: boolean;
};

const project: Project = {
  name: "Designsystem",
  active: true,
};
```

```json
{ "message": "Hallo Welt", "ready": true }
```
